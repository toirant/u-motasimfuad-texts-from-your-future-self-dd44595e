Entry for the [Texts From Your Future Self](https://make.fun/c/u-motasimfuad-texts-from-your-future-self-dd44595e) bounty on make.fun.

`main.py` writes one funny text message from the writer's future self to `/output/entry.txt`:

> Future you: the 'temporary' tattoo never faded. Neither did the guy who gave it to you - he's your landlord now.

Run it with `python3 main.py`. The program checks its own output against the gate (1–200 characters, not only whitespace) before writing.
